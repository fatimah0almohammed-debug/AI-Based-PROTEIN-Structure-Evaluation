# AI-Based PROTEIN Structure Evaluation

## Overview

This project demonstrates the use of AlphaFold3 for protein structure prediction and evaluation against an experimentally determined structure using PyMOL.

## Objective

To predict the three-dimensional structure of a protein using AlphaFold3 and evaluate the predicted structure by comparing it with the experimental structure obtained from the Protein Data Bank (PDB).

## Protein Information

* **PDB ID:** 1U72
* **Protein:** Dihydrofolate reductase (DHFR)
* **Organism:** Homo sapiens
* **Experimental Method:** X-ray diffraction
* **Resolution:** 1.90 Å
* **Chain:** A

## Tools Used

* RCSB Protein Data Bank
* AlphaFold3
* PyMOL

## Workflow

1. Retrieved the experimental protein structure and FASTA sequence for PDB ID 1U72 from the RCSB PDB.
2. Obtained the FASTA sequence for Chain A.
3. Submitted the FASTA sequence to AlphaFold3 for structure prediction.
4. Downloaded the predicted structure generated by AlphaFold3.
5. Opened the predicted and experimental structures in PyMOL.
6. Aligned the predicted structure with the experimental structure using PyMOL.
7. Evaluated the structural similarity using the RMSD value.

## Alignment Results

| Metric               | Result           |
| -------------------- | ---------------- |
| **RMSD**             | **0.404 Å**      |
| **Residues Aligned** | **186 residues** |
| **Overall Quality**  | **Excellent**    |

The AlphaFold3 predicted structure showed excellent agreement with the experimental structure. The low RMSD of **0.404 Å** indicates a high degree of structural similarity across the aligned region.

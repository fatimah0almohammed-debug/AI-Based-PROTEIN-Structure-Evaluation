# AI-Based PROTEIN Structure Evaluation

## Overview

This project demonstrates the use of AlphaFold3 for protein structure prediction and evaluation against an experimentally determined structure using PyMOL.

## Objective

To predict the three-dimensional structure of a protein using AlphaFold3 and evaluate the predicted structure by comparing it with the experimental structure from the Protein Data Bank (PDB).

## Protein Information

* **PDB ID:** 1U72
* **Protein:** Dihydrofolate reductase (DHFR)
* **Organism:** Homo sapiens
* **Experimental Method:** X-ray diffraction
* **Resolution:** 1.90 Å
* **Chain:** A

## Tools Used

* RCSB Protein Data Bank (PDB)
* AlphaFold3
* PyMOL

## Workflow

1. Retrieved the experimental protein structure and FASTA sequence for PDB ID 1U72 from the RCSB PDB.
2. Submitted the FASTA sequence to AlphaFold3 for structure prediction.
3. Downloaded the predicted protein structure generated by AlphaFold3.
4. Opened both the predicted and experimental structures in PyMOL.
5. Aligned the predicted structure with the experimental structure using PyMOL.
6. Evaluated the structural similarity using the RMSD value.

## Alignment Results

* **RMSD:** 0.404 Å
* **Residues Aligned:** 186 residues
* **Overall Quality:** Excellent agreement between the predicted and experimental structures.

The low RMSD value of 0.404 Å indicates a high degree of structural similarity between the AlphaFold3 predicted structure and the experimental structure.

## Files

* `1U72.cif` — Experimental protein structure.
* `fold_2026_08_09_23_57_model_0.cif` — AlphaFold3 predicted structure.
* `rcsb_pdb_1U72 (1).fasta` — FASTA sequence used for the AlphaFold3 prediction.
* `aligned 1U72.pse` — PyMOL session containing the structural alignment.

## Conclusion

The AlphaFold3 predicted structure showed excellent agreement with the experimentally determined DHFR structure, demonstrating the ability of AlphaFold3 to generate a highly similar protein structure for this target.
